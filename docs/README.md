# Setlist Social Documentation

This folder contains the required documentation package for the Setlist Social final project.

- `DESIGN_NOTE.md` - product audience, domain/API choice, user-owned data, protected routes, user isolation, and SignalR rationale.
- `ARCHITECTURE.md` - system diagram, route map, endpoint table, data model summary, deployment architecture, and technology rationale.
- `PROMPT_LOG.md` - major ChatGPT/Codex/Copilot sessions and accepted/rejected changes.
- `AI_REFLECTION.md` - reflection on AI assistance, mistakes, debugging, and prompting strategy.
- `SECURITY_REVIEW.md` - OAuth/session, authorization, validation, CORS, HTTPS, secrets, dependency audit, and known limitations.
- `ACCESSIBILITY_REPORT.md` - accessibility findings, implemented fixes, verification, and remaining audit work.
- `SEED_ARTIST_LISTS.txt` - curated artist names used by the simulated seed process.
